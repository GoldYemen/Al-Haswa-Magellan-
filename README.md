🌍 نبذة عن المشروع

الحسوة ماجلان تطبيق للملاحة والاستكشاف، يهدف إلى توفير تجربة عربية حديثة لاستكشاف الخرائط والمواقع، مع أدوات للمعلومات البحرية والفلكية، والتركيز على عدن وخليج عدن واليمن.

✨ المميزات

-🌐 واجهة عربية: تجربة استخدام واضحة ومناسبة للمستخدم العربي.

- 🗺️ الخرائط والملاحة: استكشاف الخرائط والبحث عن الأماكن والتنقل بين المواقع.

🎯 رؤية المشروع
